## 5. 组件规范

### 5.1 导航栏

- 高度：44px
- 背景：`#FFFFFF`
- 左侧：返回箭头（28px 方形点击区，icon 24px，颜色 `#8A8A8E`）
- 中间：标题 16px/500，左对齐（距返回箭头 4px）
- **右侧：留给微信原生胶囊按钮（关闭/更多），严禁放置任何自定义元素**

> **关键约束**：微信小程序右上角的胶囊按钮由系统渲染，固定宽度约 88px。导航栏右侧 88px 区域为"胶囊安全区"，放置搜索 icon、通知铃铛等自定义元素**必然被胶囊遮挡**。所有自定义操作入口必须放在左侧或中间区域。

### 5.2 首页顶部分段（toptabs）+ 搜索入口

- 高度：44px（与导航栏合并）
- **布局**：搜索 icon（左侧）+ toptabs（发现/北京，中间）+ 右侧胶囊安全区（不放任何元素）
- 两个 tab：「发现」+「城市名」（如"北京"）
- 字号：16px，未激活 500/Muted，激活 700/Ink
- 激活指示器：3px 高、18px 宽圆角条，主色 `#534AB7`，距底 6px 居中
- 搜索 icon：24px，颜色 `#8A8A8E`，距 toptabs 左侧 10px

> **通知入口位置**：通知 icon **不放在首页顶栏**（会挤占胶囊安全区），统一收敛到"我的"页——消息中心 cell 带未读红点。用户从任何页面想看通知都走"我的 → 消息中心"。

### 5.3 TabBar

- 高度：50px（微信小程序标准）
- 背景：`#FFFFFF`
- 无顶部分割线
- 三 tab 等宽分布：首页 / 找搭子 / 我的
- icon 24px + 文字 10px
- 未激活：`#7A7A7A`
- 激活：`#534AB7`（icon + 文字同色）

### 5.4 悬浮发布按钮（FAB）

- 尺寸：48px 圆形
- 背景：`#534AB7`
- icon：白色 plus，26px
- 阴影：`0 4px 12px rgba(83,74,183,0.35)`
- 位置：右下角，距右边 14px，距 tabbar 顶部 16px

### 5.5 卡片（信息流）

- 背景：`#FFFFFF`
- 圆角：8px
- padding：14px
- 左右 margin：12px
- 底部 margin：10px
- 无 border、无 shadow
- 分类标签：10px/600，主色文字 + 浅紫底，圆角 4px

### 5.11 发布页（按对象差异化设计）

**核心原则**：发布帖子和发布搭子是两种对象本质不同的发布行为，页面结构不应强统一。表单结构按对象特性各自设计，不追求"看起来一样"。

#### 5.11.1 统一的部分（发布流程基础设施）

所有发布页共享以下元素，保证交互一致性和视觉延续：

| 元素 | 规范 |
|---|---|
| 顶栏 | 高度 44px；左侧返回箭头 + 标题；**右侧留给微信原生胶囊按钮**（不自定义） |
| 底部操作条 | 高度 64px（含安全区）；`存草稿` 次按钮 + `发布` 主按钮 |
| 主按钮 | 44px 高 / 8px 圆角 / `#534AB7` / 15px 600 白字 |
| 次按钮 | 40px 高 / 20px 圆角 / `#F7F7F7` 底 / 13.5px 600 主色字 |
| 内联输入 | 无背景无边框，占位文字 16px（标题）/ 14px（正文/描述） |
| 配置行 | 18px icon + 13px 文字 + 右箭头，padding 13px 0 |
| 分隔线 | 1px `#F7F7F7` |

#### 5.11.2 差异的部分（按对象特性）

**发布帖子（媒体重）**：

```
┌─────────────────────────┐
│ ←  发布帖子     [微信胶囊] │  ← 顶栏
├─────────────────────────┤
│ [图1][图2][+ 添加]        │  ← 媒体区（视觉主体，顶部）
│                          │     缩略图 74×74，圆角 8px
├─────────────────────────┤
│ 添加标题                  │  ← 标题输入（16px）
│ ─────────────────        │
│ 添加正文                  │  ← 正文输入（14px）
│ ─────────────────        │
│ [穿搭][康复][文化]...      │  ← 分类 chips
│ ─────────────────        │
│ 📍 标记地点              │  ← 配置行
│ 👁 公开可见              │
│ 内容将经过安全审核后展示  │
├─────────────────────────┤
│ [存草稿]  [   发布   ]    │  ← 底部操作条
└─────────────────────────┘
```

**发布找搭子（结构重）**：

```
┌─────────────────────────┐
│ ←  发布搭子     [微信胶囊] │  ← 顶栏
├─────────────────────────┤
│ 添加标题                  │  ← 标题（视觉主角之一）
│ ─────────────────        │
│ 添加描述（水平、目标...）   │  ← 描述
│ ─────────────────        │
│ [练舞局][拼团][比赛][其他]  │  ← 类型 chips（必填）
│ ┌─────────────────────┐  │
│ │ 🕐 时间  周三 19:00 ›│  │  ← 时间地点 key-block
│ │ 📍 地点  望京 SOHO ›│  │     （紫色强化，视觉主角之二）
│ └─────────────────────┘  │
│ 👁 公开可见              │  ← 配置行
│ 🖼 + 添加参考图（选填） ›│  ← 媒体降级为可选入口
│ 应征通过后双方联系方式互见  │
├─────────────────────────┤
│ [存草稿]  [   发布   ]    │  ← 底部操作条
└─────────────────────────┘
```

#### 5.11.3 视觉主角对比

| 对象 | 视觉主角 | 实现方式 |
|---|---|---|
| 帖子 | **媒体区** | 顶部 74×74 缩略图 + 大 + 号，占满宽度 |
| 搭子 | **时间地点 key-block** | 紫色浅底（`#EEEDFE`）+ 紫色 icon + 紫色加粗文字，圆角 10px |

#### 5.11.4 媒体区的两种形态

| 形态 | 用途 | 视觉 | 交互 |
|---|---|---|---|
| **主体媒体区**（发帖页） | 内容表达的主载体 | 顶部大缩略图 + 大 + 号 | 默认展示，引导用户优先添加 |
| **可选媒体入口**（发搭子页） | 辅助参考说明 | 底部一行 `+ 添加参考图（选填）` | 点击展开媒体选择器，不强制 |

**关键约束**：搭子页的媒体入口**绝不**做成顶部大缩略图占位——那会让用户误以为"又要凑图"，发搭子门槛升高。

#### 5.11.5 配色/字号在两页的应用

| 元素 | 发帖页 | 发搭子页 |
|---|---|---|
| 标题输入 | 16px / 500 / `#1A1A1A` | 16px / 500 / `#1A1A1A` |
| 正文/描述输入 | 14px / 400 / `#3D3D3D` | 14px / 400 / `#3D3D3D` |
| chips | 12.5px / 500 / `#3C3489` | 12.5px / 500 / `#3C3489` |
| 配置行 | 13px / 400 / `#1A1A1A` | 13px / 400 / `#1A1A1A` |
| 时间地点块 | — | **紫色 key-block**：`#EEEDFE` 底 + `#534AB7` icon |
| 媒体区 | **顶部主体**：74×74 缩略图 + 48×48 大 + 号 | **底部一行入口**：`+ 添加参考图（选填）` 13px / Muted |

## 9. 开发注意事项

1. **所有 icon 使用 `currentColor`**：默认状态设父元素 color 即可继承，激活态单独覆盖 fill
2. **TabBar 使用微信原生 tabBar 配置**：不支持自定义悬浮 FAB，需用 `cover-view` 实现
3. **导航栏胶囊安全区（关键）**：微信小程序右上角胶囊按钮（关闭/更多）由系统渲染，宽度约 88px。**导航栏右侧 88px 区域严禁放置任何自定义元素**（搜索 icon、通知铃铛、头像等都会被遮挡）。所有自定义操作入口必须放在左侧或中间。搜索入口放在 toptabs 左侧，通知入口收敛到"我的"页。
4. **卡片无 shadow**：微信小程序卡片靠背景色对比浮起，不用投影
5. **分割线用 0.5px**：CSS 写 `border-top: 0.5px solid`，小程序 rpx 写 `1rpx`
6. **安全区域**：底部操作条加 `padding-bottom: calc(14px + env(safe-area-inset-bottom))`
7. **视频上传**：用 `wx.chooseVideo`，图片用 `wx.chooseMedia`，不用 input file
8. **定位**：搭子帖用 `wx.chooseLocation`（手动选点），首页城市 tab 用 `wx.getLocation`（自动定位）
