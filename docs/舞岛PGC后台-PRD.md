# 舞岛 PGC 后台 PRD v2.0

> 本版对齐 2026-08-24 实际实现。v1 基础上新增：批量导入（Excel 分类下拉/封面/置顶）、多选批量删除、媒体上传（正文图片/视频/封面）、后台列表置顶排序、官方活动加入/打卡计数。

## 1. 概述

**定位**：运营侧唯一工具——内容与活动的生产、编辑、发布、管理。**编辑后即可发布**（PGC 可信源免审），小程序端刷新即见。

**形态**：单页 Web 应用（Express 内嵌 `server/admin/`），口令登录 + JWT（12h）。数据存 `server/data/store.json`（零数据库依赖，写临时文件再 rename 防写坏）。

**入口**：`http://<host>:3100/admin/`，默认口令 `wudao-admin-dev`（生产必改 `.env`）。

## 2. 模块地图

```
数据看板 ─ 内容列表 ─ 内容编辑器 ─（批量导入）
        └ 活动列表 ─ 活动编辑器
```

## 3. 数据看板

| 指标卡 | 口径 |
|---|---|
| 已发布内容 | status=published 数（草稿数副标注） |
| 累计总阅读量 | posts[].stats.views 合计（种子含演示初值，新发从 0 累积） |
| 平均阅读完成率 | completes/views |
| 累计分享次数 | stats.shares 合计 |

> 注：MMVP 阶段 stats 为种子演示值 + 后续埋点接入点，未真实采集端侧行为。

## 4. 内容管理

### 4.1 列表

- 排序：**📌 置顶优先 → 时间倒序**（与小程序 feed 一致）
- 筛选：分类（六类下拉）/ 状态（已发布/草稿）/ 标题搜索
- 指标卡：全部/已发布/草稿/置顶中
- 行操作：编辑 / 置顶切换 / 删除（confirm）
- **多选模式**（v2 新增）：「☐ 多选」→ 复选框列（整行可点）→ 操作条（全选/反选、已选 N 篇、删除所选）→「✓ 完成多选」退出
- 批量删除 API：`POST /api/admin/posts/batch-delete {ids}` → `{deleted, missing}`（不存在的 ID 容错计数）

### 4.2 编辑器（核心）

**布局**：左编辑右预览双栏 + 右侧设置面板。

**工具栏**：H3 / H4 / **B** 加粗 / *I* 斜体 / 🔗 链接 / **🖼 图片**（上传）/ **🎬 视频**（上传）/ **＋ Call-out** / **＂ Blockquote**

**交互设计**（v2 优化）：

| 操作 | 行为 |
|---|---|
| Call-out / Blockquote | **无弹窗**：光标处直接插入可编辑骨架（占位文字自动选中，直接打字替换） |
| 图片/视频按钮 | 文件选择器 → 上传 → 插入 `![描述](url)` / `@[视频](url)`，描述选中可改 |
| 点击预览任意块 | **定位回正文编辑处**（选中对应源码 + 滚动到可视区 + 紫框高亮 0.6s） |
| 实时预览 | 渲染引擎与小程序 `md.js` 同源（所见即所得，含加粗/图片/视频） |

**右侧设置面板**：

| 设置 | 说明 |
|---|---|
| 发布动作 | 「存草稿」/「发布」；编辑已有内容 action 可改状态（草稿↔发布） |
| 置顶开关 | 首页 feed + 后台列表都置顶 |
| 无封面开关 | 纯文字紧凑卡 |
| 封面图 | **上传按钮**（即传即预览）或手填 URL；留空分类色占位 |
| 标签 | 回车添加，✕ 删除（搜索匹配用） |
| 署名 | 运营账号下拉（8 个官方号） |
| 城市 | 文本 |

**字段规范**：标题 ≤40 / 副标题 ≤60 / 正文 ≤20000 / 标签 ≤8 个。

### 4.3 批量导入（v2 新增）

入口：列表页「📥 下载模板」「📥 批量导入」。

**模板（9 列 Excel）**：

```
分类 | 标题 | 副标题 | 正文 | 封面图URL | 城市 | 作者昵称 | 标签 | 置顶
```

- **分类列（A2:A500）自带下拉**（六类标准名，选错弹提示）；置顶列下拉（是/否）
- 手输容错：简称别名（文化/赛事/大师课/舞室）+ 英文 key
- 正文支持完整 Markdown（模板第 2 行示例演示全部语法：Call-out/H3/引用/加粗/图片/视频）
- 封面 URL：`/uploads/…`（后台上传过的）或外链；留空分类色占位
- **导入即发布**；置顶行导入后双端（feed+后台）置顶

**行级容错**：分类非法/标题为空 → 仅该行失败（结果弹窗显示 Excel 行号+原因），其他行正常导入。结果弹窗：总计 N / 成功 N / 失败 N + 错误明细列表。

**不做**：标题去重（重复上传同一文件会重复生成）；导入即草稿（要草稿导入后逐篇操作）。

## 5. 活动管理

### 5.1 列表

排序置顶优先。列：活动 / 类型 / 日期 / 地点 / 关注 / **加入/打卡**（官方活动显示 `join/checkin`，其他 `—`）/ 状态 / 操作。支持多选批量删除（同内容列表交互）。

### 5.2 编辑器

- 顶部**渐变 hero 实时预览**（类型切换渐变联动、标题实时上屏）
- 字段：类型（四选一）/ 标题 / 短标题（地图气泡 ≤12 字）/ 描述 / 城市 / 地点 / 日期文本 / 时间文本 / 舞种 / 主办 / 坐标（纬度,经度）
- **日程行编辑器**：时间+事项行，＋添加 / ×删除
- 注意事项 textarea
- 发布 / 存草稿

### 5.3 官方活动参与数据（v2 新增）

用户侧加入/打卡实时写入 `joins` 记录；列表「加入/打卡」列 = 种子基数 + 真实记录数。后台可据此评估线下转化。

### 5.4 搭子需求审核与代发

#### 列表

排序：待审核优先。列：标题 / 类型 / 时间 / 地点 / 联系方式 / 状态 / 操作（通过→代发 / 驳回 / 查看活动 / 编辑）。

4 个数据卡片：待审核数 / 审核通过率 / 已发布练舞局数 / 平均应征数。

#### 审核编辑器

用户原始需求（只读）+ 代发编辑器（可编辑）双栏：

**用户原始需求（只读）**：类型/标题/描述/舞种/时间/地点/人数/微信号/参考图

**代发编辑器（通过后预填，可润色）**：

| 字段 | 说明 |
|---|---|
| 活动类型 | 练舞局（buddy）/ 拼团 / 比赛 / 其他 |
| 活动标题 | 基于用户需求预填，可编辑 |
| 活动描述 | 运营润色后的文案 |
| 时间/地点 | 预填，可编辑 |
| 舞种/人数 | 预填，可编辑 |
| 注意事项 | 默认安全提示文案 |
| 封面图 | 上传 |
| 地图定位 | 经纬度 |
| 发布账号 | 舞岛官方（只读） |
| 发起人 | 用户微信号（只读，查看应征用） |
| 通知发起人 | 发布后订阅消息通知用户 |
| 驳回原因 | 选填 |

#### 审核流程

```
用户提交需求（pending）
    ↓
运营审核：通过 / 驳回（填原因）
    ↓
通过 → 预填活动编辑器 → 运营润色 → 发布为 type=buddy 活动
    ↓
需求 status=published，linkedActivityId 写入
    ↓
（可选）订阅消息通知发起人「你的练舞局已发布」
```

#### 发布规则

- 发布账号 = 舞岛官方号（非用户头像昵称直出）
- 正文不含发起人联系方式
- 描述中不出现「加微信 xxx」等引流

## 6. 鉴权与安全

| 项 | 方案 |
|---|---|
| 登录 | 口令（`.env ADMIN_PASSWORD`）→ JWT 12h，前端 localStorage |
| API 鉴权 | Bearer JWT；模板下载支持 `?token=`（a 标签场景） |
| 上传安全 | 扩展名白名单 + 大小限制 + uuid 重命名（防穿越/注入） |
| 越权 | 全部 /api/admin/* 走 auth 中间件；无用户体系无角色 |

## 7. API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/admin/login | 口令登录 |
| GET/POST/PUT/DELETE | /api/admin/posts[/:id] | 内容 CRUD（POST/PUT 带 action: draft/publish） |
| POST | /api/admin/posts/:id/pin | 置顶切换 |
| POST | /api/admin/posts/batch-delete | 批量删除 |
| GET/POST/PUT/DELETE | /api/admin/activities[/:id] | 活动 CRUD |
| POST | /api/admin/activities/batch-delete | 批量删除 |
| POST | /api/admin/upload/image \| video | 媒体上传（图 ≤10MB / 视频 ≤100MB） |
| GET | /api/admin/import/template.xlsx | 模板下载（含下拉） |
| POST | /api/admin/import | 批量导入 |
| GET | /api/admin/stats \|
/users | 看板 / 署名账号 |

小程序侧 API（无鉴权）：`/api/content/feed?scope|city|tab`、`/api/content/posts/:id`、`/api/activities[/:id|/joined|:id/join|:id/checkin]`、`/api/search[?q=|/hot]`、`/uploads/*` 静态媒体。

## 8. 运行与部署

```bash
cd server && node app.js            # 开发：127.0.0.1:3100
cp .env.example .env                # 生产：改 ADMIN_PASSWORD + JWT_SECRET
```

生产经 Nginx 反代 `/wudao/` → 127.0.0.1:3100（去尾部 `/` 剥离前缀）；小程序 `utils/config.js` 切 `mode:'http'`。
