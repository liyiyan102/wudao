# 活动批量导入模板

> 后台「活动列表 → 📥 下载模板」获取 Excel 模板（活动类型/城市列带下拉）；「📥 批量导入」上传，**导入即发布**（列表+地图立即可见）。

## 列定义（13 列）

| 列 | 必填 | 说明 | 示例 |
|----|------|------|------|
| 活动类型 | ✅ | **下拉选择**：官方活动 / 赛事 / 大师课 / 其他 / 找搭子（简称容错：官方/比赛/课程/工作坊） | `大师课` |
| 标题 | ✅ | ≤40 字，卡片与详情大标题 | `KOD 世界总决赛中国区预选` |
| 短标题 | 选填 | 地图气泡标签，≤12 字；留空取标题前 8 字 | `KOD 预选` |
| 日期 | ✅ | 自由文本 | `8月24日` / `每周六` |
| 时间 | 选填 | 自由文本 | `14:00 - 22:00` |
| 地点 | ✅ | 具体地点 | `北京 工人体育馆` |
| 城市 | 选填 | **下拉选择**（8 城）；默认北京 | `北京` |
| 舞种 | 选填 | | `Breaking · Hip-hop` |
| 主办方 | 选填 | | `KOD 中国区组委会` |
| 描述 | 选填 | 列表卡片正文，2-3 行 | |
| 注意事项 | 选填 | 详情页底部 | `参赛提前 1 小时签到` |
| **日程** | 选填 | `时间 事项`，**分号分隔多项** | `14:00 签到;15:00 海选;21:00 决赛` |
| **封面图URL** | 选填 | 同内容导入：本地文件名（放 `server/data/uploads/`）或 `https://…` / `/uploads/…` | `kod-cover.jpg` |

## 封面图

与内容导入相同：把图片放到 `server/data/uploads/`（和后台上传同一目录），Excel「封面图URL」列填文件名；或填完整 `https://…` / `/uploads/…`。列表卡片与详情页会展示封面。

## 日程格式详解

每项「`时间` + 空格/·/- + `事项`」，多项用**分号**分隔（`;` 或 `；`），自动解析为详情页时间轴：

```
14:00 签到入场;15:00 Breaking 1v1 海选;17:00 Hip-hop 海选;21:00 决赛·颁奖
```

解析结果：

| 时间 | 事项 |
|---|---|
| 14:00 | 签到入场 |
| 15:00 | Breaking 1v1 海选 |
| … | … |

## 坐标说明（重要）

模板**不含坐标列**。导入后坐标取所选城市的中心附近随机偏移（±0.04°，约 4km）：

- 如果活动地点就在市中心 → 默认坐标基本可用
- **需要精确位置** → 导入后在「活动列表 → 编辑」里手动填「纬度,经度」（可从高德/腾讯地图拾取坐标复制）

## 官方活动（可加入打卡）

类型选「官方活动」的活动，用户端出现「加入活动 → 现场打卡」按钮；导入后 joinCount/checkinCount 从 0 开始累积。

## 行级容错

- 类型非法/标题/地点/日期为空 → 仅该行失败（弹窗显示行号+原因）
- 重复导入同一文件会重复生成（不做去重）
