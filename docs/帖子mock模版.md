## 字段说明

| 列 | 必填 | 说明 | 可选值 / 格式 |
|----|------|------|----------------|
| 分类 | ✅ | 内容分类 | PGC 四类：`康复` / `文化` / `穿搭` / `圈内`；UGC 三类：`练舞` / `上课` / `动态` |
| 标题 | ✅ | 帖子标题（≤30 字） | 自由填写 |
| 正文 | 选填 | 帖子内容（支持 \n 换行） | 留空自动生成 |
| 城市 | ✅ | 发布城市 | `北京` / `上海` / `广州` / `深圳` / `杭州` / `成都` / `武汉` / `西安` |
| 媒体 | 选填 | 媒体形态（默认自动占位） | 留空 = 自动形态；`3` = 3 张图（需提供图片）；`视频` = 视频帖 |
| 置顶 | 选填 | 是否置顶到信息流顶部 | `是` / `否`（默认） |
| 点赞 | 选填 | 点赞数 | 数字，留空随机 0-8 |
| 收藏 | 选填 | 收藏数 | 数字，留空随机 0-3 |
| 评论 | 选填 | 评论条数 | 数字，留空随机 0-2（自动生成评论内容） |

## 媒体说明（重要）

| 填法 | 卡片形态 | 需要提供什么 |
|------|----------|--------------|
| 留空 | PGC 类 → 浅紫封面+图标；UGC 类 → 纯文字紧凑卡 | 无 |
| 数字 N（如 `3`） | 详情页有 N 张图，卡片显示首图 | 真实图片：① 放 `images/mock/` 文件夹后备注文件名；② 或直接给图片 URL |
| `视频` | 卡片封面显示播放图标 | 真实视频可选：给 mp4 在线 URL；不提供则仅显示占位 |

> 备注：mock 阶段强烈建议留空——占位形态零依赖、永不裂图。真实媒体适合演示发帖/预览流程时使用（且需勾选开发者工具「不校验合法域名」）。

## 其他可选项（如需要请备注）

- **发布者**：PGC 类默认对应官方号（康复研究所/文化考古队/穿搭研究局/圈内八卦站）；UGC 类随机舞友（Bboy飞龙/Mika酱/LockLee/PopCorn/HouseCat小猫）；可备注昵称指定
- **发布时间**：默认随机近 7 天；要精确控制可备注如「今天上午」「3 天前」
- **无封面紧凑卡**：PGC 快讯类如「圈内」短讯想走纯文字卡（无浅紫封面），备注「无封面」
