# 内容批量导入模板

> 后台「内容列表 → 📥 下载模板」获取 Excel 模板（**分类列带下拉选项**）；填好后「📥 批量导入」上传，**导入即发布**。

## 列定义（9 列，按模板顺序）

| 列 | 必填 | 说明 | 示例 |
|----|------|------|------|
| 分类 | ✅ | **单元格自带下拉选项**（穿搭/康复/文化/舞室/新鲜事）；手输也支持简称 | `文化` |
| 标题 | ✅ | ≤40 字 | `嘻哈从哪来：一场持续 50 年的派对` |
| 副标题 | 选填 | ≤60 字，详情页标题下方展示 | `从 Bronx 街头到全球舞台` |
| 正文 | ✅ | 支持完整 Markdown（见下方语法） | 单元格内 `Alt+Enter` 换行 |
| **封面图URL** | 选填 | 见下方「图片怎么填」 | `book.jpg` 或 `https://…` |
| 城市 | 选填 | 城市名或 **不限**（全国可见，城市 Tab 靠后）；默认 `北京` | `上海` / `不限` |
| 作者昵称 | 选填 | 运营账号昵称；不认识默认「舞岛官方」 | `上场衣橱` |
| 标签 | 选填 | 搜索匹配用；分号/顿号/逗号分隔 | `嘻哈;历史;文化` |
| 置顶 | 选填 | **下拉是/否**；置顶后小程序 feed 与后台列表都排顶部 | `否` |

## 图片怎么填（本地批量）

Excel **不能**直接用电脑路径（`C:\…`、`/Users/…`、`file://`）当可访问 URL。任选其一：

### 方式 A：本地文件名（推荐批量）

后台点「图片」上传、批量导入，都用同一个目录 **`server/data/uploads/`**。线上导入就把文件放到服务器 `/opt/wudao/data/uploads/`。

1. 把图片/视频放进 `server/data/uploads/`（文件名不要带路径）
2. **封面图URL** 列只填文件名，例如 `book.jpg`
3. 正文里同样：`![书封](book.jpg)`、`@[宣传片](demo.mp4)`
4. 导入后正文会写成 `/uploads/book.jpg`（不再另拷一份）

### 方式 B：已上传地址 / 外链

- 后台「编辑内容」里上传一次，复制得到的 `/uploads/xxx.png`
- 或任意可公网访问的 `https://…`

## 正文 Markdown 语法（与后台编辑器/小程序渲染一致）

| 语法 | 效果 |
|------|------|
| `## 标题` | H3 章节（大标题） |
| `### 标题` | H4 小节 |
| `>>t 标题` + `>> 内容` | **Call-out 引言块**（浅紫底+紫左条，作者导读） |
| `> 内容` + `> —— 出处` | **Blockquote 引用块**（灰左线+斜体，引用他人） |
| `**文字**` | **加粗** |
| `- 条目` / `* 条目` | **无序列表** |
| `1. 条目` / `1、条目` | **有序列表** |
| `| 列1 | 列2 |` | **表格**（自动对齐/横向滑动，第二行为分隔线） |
| `![描述](图片URL或文件名)` | **正文图片**（原比例全宽，点击可预览） |
| `@[视频](视频URL或文件名)` | **正文视频**（原生播放器） |
| 普通行 | 段落 |

### 写法示例

```markdown
| 鞋款 | 质量 | 价格 | 搭配度 | 舒适度 | 更适合谁 |
| --- | ---: | ---: | ---: | ---: | --- |
| Nike AF1 Dance | 8 | 6 | 8 | 9 | 想认真跳、又想兼顾日常 |
| Nike Dunk | 8 | 5 | 9 | 8 | HipHop、转圈、日常穿 |

![书的封面](book.jpg)

@[大师课宣传片](/uploads/demo-video.mp4)
```

**Excel 换行**：单元格内按 `Alt + Enter`（Mac：`Option + Command + Enter`）换行，空行分隔段落。

## 行级容错

- 某行分类非法/标题为空/本地图找不到 → **仅该行失败**（弹窗显示行号+原因），其他行正常导入

## 注意事项

1. **导入即发布**；置顶行导入后在小程序 feed 与**后台列表**均置顶展示
2. 重复导入同一文件会生成重复内容（不做标题去重）
3. 视频建议用后台「编辑内容 → 🎬 视频」上传后复制 URL（≤100MB），或把文件放进 `server/data/uploads/` 后填文件名
4. 后台列表可**拖动排序**（清空筛选后拖左侧把手），顺序同步到小程序
