## 字段说明

| 列 | 必填 | 说明 |
|----|------|------|
| 类型 | ✅ | `官方活动` / `赛事` / `大师课` / `Jam`（决定封面渐变与 pin 颜色） |
| 标题 | ✅ | 活动名（卡片大标题） |
| 介绍 | 选填 | 一段描述（列表卡正文），留空自动生成 |
| 城市 | ✅ | 北京/上海/广州/深圳/杭州/成都/武汉/西安 |
| 地点 | ✅ | 具体地点名（如"北京 工人体育馆"） |
| 坐标 | 选填 | `纬度,经度`（如 `39.93,116.44`）；留空自动生成 |
| 日期 | ✅ | 如 `8月24日` / `每周六` |
| 时间 | ✅ | 如 `14:00 - 22:00` |
| 舞种 | 选填 | 如 `Breaking · Hip-hop` |
| 主办 | 选填 | 主办方名称 |
| 关注数 | 选填 | 数字，默认随机 100-800 |
| 日程 | 选填 | 分号分隔：`14:00 签到;15:00 海选;21:00 决赛` |
| 注意事项 | 选填 | 一段文字 |
